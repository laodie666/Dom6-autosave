# Dominions Save Manager

**Dominions Save Manager** is a small Python script I made to make save management easier in Dominions, so I can avoid manually making new folders and dragging files around.  
Presumably, it saves tons of time when testing battles or doing save scumming in Single Player :D

![Dominions Save Manager Screenshot](https://github.com/user-attachments/assets/20528ca3-a227-4bfc-9a75-923dbedbc637)

## Features

- Manual save and load of your Dominions games  
- Autosaving support  
  - Leave the script open while you play with autosaving turned on and it will automatically back up new turns coming in.
- Has Windows Linux support! (Linux port done by zorgos965)

## How to run

- Download the exe by clicking the releases on the right and download the exe or just click Code and download zip.
- Double click the exe, and it should just work 👍
